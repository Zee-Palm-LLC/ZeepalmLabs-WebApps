# ZeepalmLabs WebApps

Websites, landing pages and web apps built by Zeepalm Labs. Each folder is a self-contained project with its own README, code and assets.

## Websites

| Website | What it is | Built with | Live demo |
|---|---|---|---|
| [Repline](repline) | Scroll-driven story page for a smart gym tracker. A scrubbed lift video with live bar-speed overlays, a sideways how-it-works section, a set you can try, and an animated closing run to the waitlist. | React, Vite, GSAP, Lenis | [zeepalm-repline.vercel.app](https://zeepalm-repline.vercel.app) |
| [Ember](ember) | Wood-fire grill house. A scroll-scrubbed steak cook with a live kitchen ticket and probe, a canvas flame you can switch between woods, a 45-day dry-age chamber, a steak builder with a live cross-section, a printed menu and a full table booking flow. | React, Vite, GSAP, Lenis, Canvas | [zeepalm-ember.vercel.app](https://zeepalm-ember.vercel.app) |
| [Aurum AI](aurum-ai) | AI wealth dashboard. A live canvas network of your portfolio, sectors and holdings, with streaming crypto prices, paper trading, an in-browser AI analyst, filters, search and a position view for every holding. Visual style adapted from a Dribbble concept by George Railean / Fuselab Creative. | React, Vite, GSAP, Canvas | [zeepalm-aurum.vercel.app](https://zeepalm-aurum.vercel.app) |
| [FitMove](fitmove) | Fitness dashboard recreated pixel for pixel from a Dribbble design, with an intro that builds the page like a story of the day: vitals, weekly activity, goal rings, today's run on a live-drawn route, meals, classes and schedule. Every chart, menu, calendar and list is interactive. Design by Ahmad S. Afandi / Peterdraw Studio. | React, Vite, GSAP, SVG | [zeepalm-fitmove.vercel.app](https://zeepalm-fitmove.vercel.app) |
| [THAW](thaw) | AI mental health landing page. A pixel-perfect hero from a Dribbble design, where a frozen head turns 360° as frost melts off the page. Further sections cover the approach, a pinned how-it-works track, a live session preview, the science, plans, a working mini-assessment and a crisis-support footer. Design by Kris Anfalova. | React, Vite, GSAP, Lenis, WebGL | — |

## Adding a website

1. Create a folder at the root, named in lowercase with dashes (for example `coffee-roaster`).
2. Give it a `README.md` that says what it is, how to run it and how to deploy it.
3. Add a row to the table above.
